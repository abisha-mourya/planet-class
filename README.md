# Planet Class

A beginner Python OOP project completed as part of the freeCodeCamp Python Certification course.

# Description

A Planet class that creates planet objects, validates their attributes, and provides methods to display planet information and describe their orbit.

# Concepts Used

- Classes and objects
- `__init__()` method
- Instance attributes
- Methods
- Type checking
- Exception handling
- `__str__()` method
- f-strings

# Features

- Creates planet objects
- Validates planet information
- Displays planet details
- Describes the planet's orbit
